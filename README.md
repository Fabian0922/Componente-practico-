# Componente Práctico - Programación

Este repositorio contiene el desarrollo del componente práctico para el curso de Programación. El proyecto integra diversas funcionalidades diseñadas bajo un enfoque de programación orientada a objetos (POO), asegurando modularidad, eficiencia y limpieza de código.

## Descripción del Proyecto
El sistema (denominado internamente como "3 en 1") resuelve tres escenarios distintos de lógica y gestión de datos, implementando estructuras de control avanzadas y manejo de excepciones.

### Características Principales:
*   **Arquitectura Modular:** Separación clara entre lógica de negocio y presentación.
*   **Uso de POO:** Implementación de clases, herencia y polimorfismo.
*   **Validación de Datos:** Control estricto de entradas para prevenir errores de ejecución.
*   **Logs Personalizados:** Generación de registros para seguimiento de operaciones.
